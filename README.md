🌍 Tripadvisor Clone

A Tripadvisor Clone website created using HTML and CSS. This project is a frontend recreation inspired by the Tripadvisor travel website, focusing on layout, styling, navigation, destinations, hotels, restaurants, and travel experiences.

🛠️ Technologies Used

HTML5

CSS3

Flexbox

CSS Grid

Responsive Design

✨ Features

🏠 Responsive homepage

🔍 Search section

🏨 Hotel and accommodation cards

🍽️ Restaurant section

🌍 Popular destinations

⭐ Ratings and reviews UI

📸 Travel destination images

📱 Responsive layout

🧭 Navigation bar

📋 Footer section

🚀 How to Run

Clone this repository:

git clone https://github.com/your-username/tripadvisor-clone.git


Open the project folder.

Open index.html in your browser.

That's it! No backend or installation is required.
